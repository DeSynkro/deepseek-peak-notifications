# opencode-deepseek-peak-notifications

OpenCode 1.19 TUI sidebar alert for DeepSeek peak and off-peak pricing.

This package is the OpenCode adapter for DeepSeek Peak Notifications. It shows a sidebar card, a countdown to the next pricing change, and a toast when peak starts or ends.

## Install

From the project root:

```sh
cd opencode
bun install
cd ..
opencode plugin --global "$(pwd)/opencode"
```

Restart OpenCode after registering the plugin.
